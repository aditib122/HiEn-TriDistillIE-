# HiEn
HiEn is a framework for Hindi–English medical information extraction. It explores how knowledge from multiple language- and domain-oriented teacher models can be transferred into a compact student model for handling medical text across two languages.
For Re-running
The training cells were originally developed for Google Colab and may reference Google Drive paths, saved dataset splits, and teacher checkpoints. Update those paths to match your environment before executing the heavy training cells.
The pre-populated tables and plots at the top are reported final/robustness summaries for convenient inspection. They are not a substitute for rerunning the corresponding experiment cells.
